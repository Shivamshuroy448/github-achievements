# GitHub Profile Achievements Guide

### Achievements Track
1. **Quickdraw**: Closed an issue or pull request within 5 minutes of opening it.
2. **YOLO**: Merged a pull request without code review.
3. **Pair Extraordinaire**: Co-authored a commit that was merged.
4. **Pull Shark**: Merged 2 PRs (Bronze), 16 PRs (Silver), 128 PRs (Gold).
